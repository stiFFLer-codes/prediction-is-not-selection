## Fields S2AND actually carries

Signature record, all eight datasets, identical schema: `signature_id`, `paper_id`, `author_id`, and an `author_info` object with `first`, `middle`, `last`, `suffix`, `position`, `block`, `given_block`, `affiliations`, `email`. Nothing else.

`author_id` is **not** the label. It is a Semantic Scholar author id that disagrees with the gold clustering, so the label of record is the cluster id from `*_clusters.json`.

## Not ingested, and why

- `*_papers.json` (~3.4 GiB across the eight) and `*_specter.pickle` (~3.0 GiB): carry paper-level context (title, venue, year, co-authors) that Phase 2.2 mechanisms may want, but nothing the two-axis check needs. Re-fetchable by extending the file list in `fetch_s2and.py`.
